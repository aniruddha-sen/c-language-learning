# C Language Learning Journey

This repository documents my journey of learning the C programming language from the fundamentals.
The goal of this repository is to practice core programming concepts, maintain structured notes, and keep track of my progress as I build a strong foundation in programming.

All programs are written and organized topic-wise so that the learning process remains clear, systematic, and easy to review later.

## What This Repository Contains

### 1. Programs

The `01-basics` folder contains small programs written to understand the fundamental concepts of C programming.

Current programs include:

* **Hello World** – the first program used to understand program structure.
* **Sum of Two Numbers** – taking input and performing arithmetic operations.
* **Swap Using Third Variable** – understanding variable storage and swapping logic.
* **Swap Without Third Variable** – practicing logical manipulation of values.

More programs will be added as I continue learning topics like operators, control statements, functions, arrays, and pointers.

---

### 2. Notes

Along with code, this repository also contains short notes for revision.

Current notes:

* **01_introduction.md** – basic introduction to C language and programming concepts.
* **02_tokens.md** – explanation of C tokens such as keywords, variables, constants, and operators.

These notes are written primarily for **quick revision and concept clarity**.

This repository helps me practice these habits from the beginning.

---

## How to Run the Programs

To compile and run a program using GCC:

```
gcc filename.c -o program
./program
```

Example:

```
gcc C01_hello_world.c -o hello
./hello
```
