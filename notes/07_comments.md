# Comments in C

Comments are non-executable statements used to explain code and improve readability.

They are ignored by the compiler and do not affect program execution.

---

# Types of Comments

C supports two types of comments:

* Single-line comments
* Multi-line comments

---

# Single-Line Comments

Single-line comments are used to write short explanations.

### Syntax:

```c id="com1"
// This is a single-line comment
```

### Example:

```c id="com2"
int a = 10;  // variable declaration
```

---

# Multi-Line Comments

Multi-line comments are used for longer explanations or documentation.

### Syntax:

```c id="com3"
/*
This is a
multi-line comment
*/
```

### Example:

```c id="com4"
/*
This program calculates
the sum of two numbers
*/
int sum = a + b;
```

---

# Why Use Comments?

Comments are useful for:

* Explaining complex logic
* Improving code readability
* Making code easier to maintain
* Helping others understand your code

---

# Best Practices

* Write clear and meaningful comments
* Avoid unnecessary or obvious comments
* Keep comments concise and relevant
* Update comments when code changes

---

# Summary

Comments are an essential part of programming.
They help in understanding, maintaining, and improving the quality of code.
