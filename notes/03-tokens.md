# C Tokens

## Definition
In the C programming language, the smallest individual units of a program are called **tokens**.  
The compiler identifies these tokens while analyzing the source code.

In simple terms, tokens are the **basic building blocks of a C program**.

---

## Types of Tokens

There are five main types of tokens in C:

1. Keywords  
2. Identifiers  
3. Constants  
4. Operators  
5. Special Symbols  

---

## 1. Keywords

Keywords are **reserved words in C** that have predefined meanings and cannot be used as variable names.

### Examples

- int
- float
- char
- if
- return

---

## 2. Identifiers

Identifiers are the **names given to variables, functions, arrays, or other user-defined items**.

### Examples

- age
- totalSum
- student_name
- calculateArea

---

## 3. Constants

Constants are **fixed values that do not change during program execution**.

### Examples

- 10
- 3.14
- 'A'
- "Hello"

---

## 4. Operators

Operators are **symbols used to perform operations on variables and values**.

### Examples

- `+` (Addition)
- `-` (Subtraction)
- `*` (Multiplication)
- `/` (Division)
- `%` (Modulus)

---

## 5. Special Symbols

Special symbols are characters that have specific meaning in the structure of C programs.

### Examples

- ( )
- { }
- [ ]
- ;
- ,
